# Security policy

Report a potential vulnerability privately through this repository's
[GitHub private vulnerability reporting](https://github.com/pcvantol/djconnect-pi-releases/security/advisories/new)
form. Do not publish proof-of-concept details in a public issue before the
maintainer has assessed the report.

This repository distributes Raspberry Pi release artifacts, release metadata,
and install copy. Include the affected release version and checksum when the
report concerns a published artifact.

For non-security feedback, use the normal GitHub issue tracker.
